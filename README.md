# WA Ringan

Pembungkus ringan WhatsApp Web berbasis Tauri (WebView2) untuk Windows.

## Cara build (tanpa install apa pun di PC)
1. Upload semua isi folder ini ke repo GitHub baru.
2. Buka tab **Actions** > **Build WA Ringan (Windows)** > **Run workflow**.
3. Tunggu ±10 menit, unduh artifact **WA-Ringan-Windows**.
4. Jalankan installer `.exe`, scan QR dari HP seperti biasa.
